### 📚 2. PDF Notes Assistant — AI-Powered PDF Question Answering

A web-based study assistant that allows users to upload PDF documents and ask questions about their contents. It uses **Retrieval-Augmented Generation (RAG)** to retrieve relevant document passages and generate context-based answers.

**Key Features**
- 📄 Upload and process PDF documents
- ✂️ Split extracted text into overlapping chunks
- 🧠 Generate text embeddings using Hugging Face
- 🔎 Retrieve relevant content using ChromaDB similarity search
- 🤖 Generate answers using a Groq-hosted language model
- 🌐 Simple web interface built with Flask
- 🎓 Support document-based revision and exam preparation

**Tech Stack:** `Python` `Flask` `LangChain` `ChromaDB` `Hugging Face Embeddings` `Groq` `PyPDF` `HTML` `CSS`
